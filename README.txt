GPC GROUP OF EDUCATION INSTITUTIONS - WEBSITE

Files:
- index.html: Main homepage
- style.css: Responsive premium navy/gold styling
- script.js: Mobile navigation, scroll reveal and active navigation
- enroll.html: Phase 2 placeholder route
- assets/gpc-logo.png: Uploaded GPC logo
- assets/director.png: Uploaded director photograph
- assets/reference-banner-*.jpg: Uploaded reference banners

HOW TO RUN
1. Extract the ZIP file.
2. Open the gpc-education-website folder in VS Code.
3. Install the VS Code extension "Live Server" (if not already installed).
4. Right-click index.html and choose "Open with Live Server".

NOTES
- Internet connection is needed for Google Fonts and Lucide icons CDN.
- The university cards are editable display entries, not claims of verified current affiliation.
- Replace or update course/university information only after confirming current availability and recognition.
- The enrolment page is a Phase 2 placeholder; it does not submit or store student information.
- Update WhatsApp number and contact details if the institution changes them.
